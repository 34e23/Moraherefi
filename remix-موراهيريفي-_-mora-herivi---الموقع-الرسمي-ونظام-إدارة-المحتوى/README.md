# مشروع موراهيريفي (Mora Herivi) — الموقع الرسمي الموثق ونظام إدارة المحتوى (CMS)

تطبيق ويب متكامل يجمع بين موقع رسمي فاخر لمنتج **شراب موراهيريفي (Mora Herivi)** العشبي ونظام إدارة محتوى خاص آمن (Headless Full-Stack CMS) مبني بالكامل بأحدث معايير الأمان والتصميم الطبي الصيدلاني.

---

## 1. المميزات والمكونات المنجزة

### أ. الموقع العام للجمهور (بدون تسجيل دخول)
- **هوية بصرية فاخرة**: درجات البنفسجي الملكي العميق (`#2D1445`)، اللافندر (`#F4F1FA`)، والليلك (`#7C3AED`) مع لمسات حجر الترافرتين.
- **دعم كامل ومتقن للغة العربية (RTL First)**: خطوط عربية صيدلانية معتمدة (**Tajawal** و **Cairo**).
- **عرض المنتج الموثق**:
  - عبوة 120 مل زجاج صيدلاني معتم.
  - نكهة البرتقال الطبيعية.
  - تنبيه المطابقة الرسمية المعتمد.
- **عرض المكونات الفعالة بدقة تامة**:
  - **مستخلص أوراق اللبلاب**: 17.5 ملغ لكل 2.5 مل.
  - **مستخلص عرق السوس**: 10.8 ملغ لكل 2.5 مل.
  - **مستخلص عشبة الزعتر**: 10.7 ملغ لكل 2.5 مل.
  - توضيح أساس القياس المعياري (لكل 2.5 مل) دون أي تحريف أو تغيير.
- **إرشادات الاستعمال والتحذيرات الرسمية**: شروط الحفظ (<25°C)، طريقة الاستخدام، والتحذيرات المعتمدة، وإخلاء مسؤولية طبي واضح.
- **معرض الصور والتغليف**: صور فائقة الدقة لزجاجة الدواء والمستخلصات العشبية والرقابة المخبرية مع نافذة تكبير (Lightbox).
- **المقالات والبحوث الطبية**: مكتبة مقالات تثقيفية موثقة مع قارئ كامل مدمج.
- **الأسئلة الشائعة**: أكورديون تفاعلي للإجابة على تساؤلات الجمهور.
- **نموذج الاتصال ومكافحة السبام**: نموذج مراسلة محمي بـ Honeypot ومحدد معدل الطلبات (Rate Limiting) وتخزين فوري في قاعدة البيانات.

### ب. لوحة تحكم المشرفين الخاصة (Private Secure CMS)
- **بوابة دخول مشفرة**: إمكانية الوصول عبر الأيقونة المشفرة أو الرابط المباشر `#admin`.
- **التهيئة الأولية الذاتية (Zero-Default Password)**: في حال عدم وجود أي مشرف، تتيح شاشة التهيئة لمرة واحدة فقط إنشاء حساب المشرف الرئيسي (Super Admin)، وتُقفل فورياً بعد ذلك.
- **إدارة مواصفات المنتج**: تعديل أسماء المنتج، الأحجام، النكهات، والتحذيرات، وتفعيل زر "المطابقة النهائية المعتمدة للملصق".
- **إدارة المكونات (CRUD)**: إضافة وتعديل وحذف المكونات مع أسس القياس وتراكيز المواد الفعالة.
- **إدارة الصفحات الثابتة (CRUD)**: إنشاء وتعديل صفحات الموقع مع مسار مخصص (Slug) وحالة النشر.
- **إدارة المقالات والأبحاث (CRUD)**: كتابة وتعديل المقالات وربط الصور.
- **صندوق رسائل الجمهور**: إدارة الرسائل الواردة وتصنيفها (جديدة، مقروءة، تم الرد) وإمكانية الرد عبر البريد.
- **سجلات الأمان والتدقيق (Audit Logs)**: تسجيل كل حركة دخول وتعديل وحذف مع عنوان IP والوقت وحالة العملية.
- **إدارة حسابات المشرفين (RBAC)**:
  - **Super Admin**: كامل الصلاحيات بما فيها إدارة المستخدمين والنسخ الاحتياطي.
  - **Content Admin**: تعديل ونشر المحتوى دون إدارة المستخدمين.
  - **Read-Only Admin**: معاينة الإحصائيات والسجلات فقط دون صلاحية التعديل.
- **النسخ الاحتياطي والاستعادة (Disaster Recovery)**:
  - تصدير كامل لقاعدة البيانات بضغطة زر بصيغة JSON.
  - استعادة قاعدة البيانات من ملف نسخة سابقة مع فحص سلامة الهيكل وتسجيل العملية.

## 2. معايير الأمان المنفذة (Security Architecture)

1. **تشفير كلمات المرور**: استخدام خوارزمية `crypto.scrypt` المعتمدة مع ملح عشوائي مشفر (Cryptographic Salt) لكل حساب ومقارنة آمنة زمنياً (`crypto.timingSafeEqual`) لمنع هجمات التوقيت.
2. **الحماية من التخمين (Brute-Force Protection)**: فئة `RateLimiter` تقوم بقفل المحاولات الفاشلة مؤقتاً لمدة 15 دقيقة بعد 5 محاولات متتالية.
3. **الجلسات المشفرة**:
   - استخدام ملفات تعريف ارتباط `HttpOnly` و `SameSite=Lax` مع رموز جلسة 256-بت عشوائية.
   - التحقق الصارم في كل نقطة نهاية محمية في الخادم (`requireAuth`).
4. **حماية المدخلات ومكافحة الثغرات**:
   - دالة `sanitizeInput` لتطهير المدخلات ومنع حقن XSS.
   - حقل Honeypot خفي لمنع روبوتات البريد العشوائي (Spam Bots).
   - ترويسات أمان صيدلانية (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy`).
   - حجب رسائل الأخطاء الداخلية عن المتصفح لمنع تسريب البنية التحتية.
5. **الفصل التام بين المحتوى العام والبيانات الإدارية**:
   - واجهة برمجة التطبيقات العامة (`/api/public/*`) ترجع فقط المحتوى المنشور (`isPublished: true`).
   - لا يتم تسريب أي كلمات مرور أو رموز أو مسودات للجمهور.
